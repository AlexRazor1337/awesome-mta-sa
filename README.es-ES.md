> Lista de recursos gratuitos/código abierto para MTA:SA y herramientas relacionadas.  

Multi Theft Auto: San Andreas (MTA:SA) es una modificación multijugador del juego de Rockstar North que añade funcionalidad multijugador en línea.

## Cómo contribuir

Para añadir cualquier recurso, simplemente crea un pull request. Si vas a añadir un recurso, debe ser gratuito y de código abierto.

## Recursos

- [mtasa-chat2](https://github.com/nrzull/mtasa-chat2) - Implementación CEF del chat de MTA:SA con algunas características nuevas.
- [aibots](https://github.com/DimDey/aibots) - Un recurso para manipular y crear un jugador artificial que puede disparar, perseguir o buscar a su objetivo.
- [lockpick](https://github.com/httpRick/lockpick) - Mecánicas de ganzúas como las de otros juegos.
- [gradmin](https://github.com/rifleh700/gradmin) - Panel de administración alternativo para MTA:SA.
- [mtasa remastered hud](https://github.com/Haxardous/mtasa-remastered-hud) - HUD original remasterizado en HD.
- [draw-distance](https://gitlab.com/IIYAMA12/draw-distance) - Mejora la distancia de visualización de todos tus recursos que utilicen archivos de mapas. 
- [mta-cl_performance](https://github.com/jmcdutra/mta-cl_performance) - Monitor de rendimiento similar al de FiveM.
- [mta-add-models](https://github.com/Fernando-A-Rocha/mta-add-models) - Carga sencilla de nuevos modelos, editor personalizado para colocar nuevos objetos.

## Librerías y utilidades

- [DBify](https://github.com/ov-sa/DBify-Library) - Librería de gestión de bases de datos asíncrona basada en MySQL.
- [ConGuard](https://github.com/Lpsd/ConGuard) - Herramienta auxiliar de red/conexión para MTA:SA.
- [mta-discord-webhook-library](https://github.com/FilexGH/mta-discord-webhook-library) - API de Discord Webhook para servidores de MTA.
- [MTA-dxGUI](https://github.com/TheNormalnij/MTA-dxGUI) - Librería dxGUI genial y potente para MTA.
- [pAttach](https://github.com/Patrick2562/mtasa-pAttach) - Unión a huesos optimizada utilizando nuevas funciones/eventos de MTA. 
- [Beautify](https://github.com/ov-sa/Beautify-Library) -  Potente librería de interfaz de usuario basada en DX.
- [editor_addon_lights](https://github.com/patrikjuvonen/editor_addon_lights) - Añadir luces Ren712 utilizando el editor de mapas predeterminado.
- [MTA_2FA-lib](https://github.com/Inder00/MTA_2FA-lib) - Librería de autenticación de dos factores.
- [mtasa-resource-compiler](https://github.com/cleoppa/mtasa-resource-compiler) - Cifra todos los archivos de tu recurso. 
- [mtasa-git-resource-updater](https://github.com/cleoppa/mtasa-git-resource-updater) - Actualiza remotamente el sistema que publicas en GitHub.
- [MTA rounded rectangle](https://github.com/prndv/MTA_rounded_rectangle) - Crea rectángulos con bordes redondeados.
- [dgs](https://github.com/thisdp/dgs) - Sistema de Interfaz Gráfica de Usuario Dx de Thisdp.
- [mtasa-utilities](https://github.com/Loki214/mtasa-utilities) - Algunas utilidades (gráficos, ruido de Perlin, sockets, etc.).
- [MTA Stream](https://github.com/Wolfee-J/MTA-Stream) - Cargador de mapas personalizados para MTA-SA.
- [check](https://github.com/rifleh700/check) - Librería simple de verificación de tipos de argumentos Lua/MTA para MTA:SA.
- [MTA Indicators](https://github.com/forkerer/MTA-indicators) - Sistema de indicadores escrito en Lua, capaz de mostrar cientos de indicadores sin lag. 
- [MTA Escalator](https://github.com/jayceon123/mta-escalator) - Escaleras mecánicas de GTA:SA con ingeniería inversa en Lua.
- [SA Menu](https://github.com/httpRick/SA-Menu) - Menú estilo GTA:SA.
- [MTASA NativeUI](https://github.com/Allerek/MTASA-NativeUI) - Menús estilo GTA:V.
- [custom-data](https://github.com/srslyyyy/custom-data) - Sistema de datos de elementos personalizados basado en tablas de Lua.
- [MTA SAMP OBJ](https://github.com/Fernando-A-Rocha/MTA-SAMP-OBJ) - Carga mapas de SAMP (compatible con mapas exportados con TextureStudio e incluso con modelos personalizados)
- [mta-add-models](https://github.com/Fernando-A-Rocha/mta-add-models) - Te permite añadir nuevos modelos a tu servidor.
- [MTA-BinaryDataTools](https://github.com/forkerer/MTA-BinaryDataTools) - Este recurso permite trabajar con formatos de datos binarios.
- [Bootloader](https://github.com/botder/mtasa-bootloader) - Un recurso para la carga inicial del servidor y el mantenimiento de recursos activos. 
- [3D-editor](https://github.com/Derbosik/3DEditor) - Herramienta fácil de usar para editar las posiciones de objetos 3D.
